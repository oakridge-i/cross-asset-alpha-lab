# N1 data implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Freeze a locally reproducible ten-ETF data vintage and establish whether its prices and corporate actions can support N2.

**Architecture:** Separate immutable acquisition, deterministic normalization and quality evaluation. Keep source bodies and normalized tables local; commit hashes, code, synthetic tests and compact evidence. A failed quality gate is a valid recorded outcome, never an implicit repair.

**Tech Stack:** Python 3.14; pinned yfinance, pandas, exchange-calendars, pytest; standard-library JSON/SHA-256/CSV. BeautifulSoup/pypdf for independently sourced corporate-action evidence.

**Spec:** RESEARCH_PROTOCOL.md sections 2–4, AGENTS.md, docs/MASTER_PLAN.md N1.

## Global Constraints

- Universe SPY,EFA,EEM,IEF,TLT,LQD,HYG,GLD,DBC,BIL; USD; daily bars; end-exclusive 2026-10-06.
- Raw observations retain source/retrieval provenance; historical availability is modeled 18:00 America/New_York, explicitly not point-in-time.
- No strategy calculations, parameter selection, reserved performance opening, paid data, publishing, or AAPL modifications.
- No silent forward fill, row removal, price repair, duplicate aggregation, or double dividend/split adjustment.
- Unknown action basis or a material unresolved data defect blocks N2 on real data.
- All real data acquisitions, QA and replays, including failures, get append-only started/terminal events.

## Review Focus

1. Incomplete or malformed upstream response must fail, retaining acquired evidence and failure log.
2. Split plus dividend on one date must preserve wealth in consistent share units.
3. Future split adjustment must not alter past reconstructed prices or total-return ratios.
4. Calendar closures/early closes and weekend payable dates must not create executable stale bars.
5. Offline replay must detect altered bytes, absent files, unsafe paths and changed transformation inputs.
