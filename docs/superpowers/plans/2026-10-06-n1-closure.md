# N1 closure implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the five N1 blocking items (DECISIONS D015) and issue a final N1 verdict on a corrected, reproducible data vintage.

**Architecture:** Issuer evidence gains two source kinds (a locally captured Invesco JSON for DBC, a "no distributions" document for GLD). Reconciliation results drive an explicit, frozen corrections file; normalize applies it as a separate derived vintage. The Yahoo source snapshot is never modified.

**Tech Stack:** Python 3.14, pandas, requests, pytest (existing pinned environment, no new dependencies).

**Spec:** user decisions of 2026-10-06 (issuer data is authoritative where it disagrees with Yahoo; DBC history captured from Invesco via browser; GLD no-distribution status from an issuer document), DATA_CONTRACT.md, RESEARCH_PROTOCOL.md sections 2-4, AGENTS.md, DECISIONS D012-D015, docs/n1/N1_REPORT.md.

## Global Constraints

- Universe SPY,EFA,EEM,IEF,TLT,LQD,HYG,GLD,DBC,BIL; window common_start 2007-05-30 .. cutoff 2026-10-05; source snapshot data/snapshots/20261006T103809-a4a22ec667 is the only Yahoo input and is never re-acquired or modified.
- No silent forward fill, row removal, price repair, duplicate aggregation, or double dividend/split adjustment. Corrections are explicit, per event, with issuer source reference, frozen as a separate vintage.
- Tolerance and gate rules from D013/D014 are unchanged.
- All real runs append started/terminal events to experiments/EXPERIMENT_LOG.jsonl; runs start from a clean committed tree (commit the log line after each run).
- No strategy statistics. English commits with trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (implementers) ; Russian project documents in AGENTS.md style.
- Run code as `PYTHONPATH=src .venv/Scripts/python -m alpha_lab ...`; tests `PYTHONPATH=src .venv/Scripts/python -m pytest -q -p no:cacheprovider --basetemp=$TEMP/<name>`.

## Review Focus

1. A local capture file whose bytes do not match its declared sha256 must fail evidence acquisition (failed event, partial evidence frozen).
2. A correction for an ex-date where Yahoo and issuer already match, or an unknown ticker/date, must be rejected, not silently applied.
3. Removing a Yahoo-only event is allowed only when the issuer lists an explicit zero-amount row on that ex-date; otherwise the event stays unresolved.
4. A corrected vintage must not change prices, splits or any non-corrected dividend row; TR changes only from the corrected sessions onward.
5. Replay of the corrected derived vintage must reproduce bytes including the corrections file; tampering with corrections fails replay.

### Task 2: Corrections vintage

**Files:**
- Create: `src/alpha_lab/corrections.py`, `tests/test_corrections.py`
- Modify: `src/alpha_lab/normalize.py`, `src/alpha_lab/pipeline.py`, `src/alpha_lab/reconcile.py`, `src/alpha_lab/__main__.py`, `tests/test_normalize.py`, `tests/test_pipeline.py`

**Interfaces:**
- Consumes: comparison.json (Task 1 shape incl. `issuer_zero_dates`), reconciliation payable.json.
- Produces: `derive(comparison: dict, evidence_ref: str) -> dict` returning `{ticker: {ex_date: {action: "add"|"replace"|"remove", yahoo_amount, issuer_amount, payable_date, source}}}`. Rules: `issuer_only` -> add issuer amount (as-traded); `amount_mismatch` -> replace with issuer amount; `yahoo_only` -> remove only if ex_date in `issuer_zero_dates`, else no correction (stays unresolved). Nothing else is corrected.
- Produces: `corrections_run(root, reconciliation_snapshot, parent=None) -> Path` freezing `data/corrections/<run_id>/{corrections.json, payable.json}`; payable.json = reconciliation payable plus actual payable for add/replace events.
- Produces: `normalize(..., corrections=None)`; output gains columns `dividend_basis` (`source` | `issuer_correction`) and `dividend_correction_source` (empty unless corrected). Corrected rows: `dividend` = issuer as-traded amount (0 for remove), `source_dividend` unchanged; TR uses corrected `dividend`. A correction whose ex-date is not a session in the frame, or whose `yahoo_amount` disagrees with the source event, raises ValueError.
- Produces: CLI `corrections RECONCILIATION --root . [--parent]`; `audit SNAPSHOT --payable P --corrections C`; `reconcile SNAPSHOT EVIDENCE --corrections C`; derived snapshot stores `corrections.json`; replay rebuilds with it.
